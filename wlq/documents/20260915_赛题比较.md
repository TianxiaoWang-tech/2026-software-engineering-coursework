# 中国软件杯 A 组赛题简要比较

| 赛题 | 难度 | 简要分析 |
|---|---|---|
| **A3 个性化资源生成与学习多智能体** | 中高 | 主题贴近学习场景，界面和功能容易做出展示效果，开发限制也少。优点是创新空间大，缺点是内容质量和课程资料准备比较费时间。 |
| **A4 智能仓储仿真** | 很高 | 仓储流程清楚，做好搬运和调度后成绩比较直观。优点是有实际应用价值，缺点是仿真平台和规则较难上手，调试时间可能较长。 |
| **A5 景区导览服务 AI 数字人** | 中 | 数字人效果直观，答辩时容易吸引评委，软件也方便演示。优点是硬件要求不高，缺点是语音、表情和问答要同时做好，细节打磨较多。 |
| **A6 智慧校园 AI 原生智能体平台** | 中 | 校园题材熟悉，容易找到使用场景，低代码也能减少开发工作。优点是功能可以灵活设计，缺点是需要先熟悉金蝶平台，学习不顺会影响进度。 |
| **A7 机器狗消防侦察与救援** | 极高 | 机器狗和 AR 展示很有冲击力，完成后作品辨识度高。优点是亮点突出，缺点是依赖专用设备和现场条件，成本高，普通软件团队不太适合。 |
| **A8 四旋翼无人机位姿控制优化** | 很高 | 更看重控制算法和仿真结果，适合喜欢研究、愿意做实验的队伍。优点是技术含量高，缺点是数学要求较高，前期学习和调参会比较辛苦。 |
| **A9 OpenHarmony 家居设备控制系统** | 中低 | 家居控制功能容易理解，灯光、门禁等内容也方便做演示。优点是难度相对低、可用仿真完成，缺点是创新空间有限，需要做好鸿蒙适配。 |

## 综合建议

- **1、选 A6**：前提是能申请并熟悉金蝶 AI 苍穹平台；校园场景容易调研，低代码能降低开发量，功能和展示空间都比较充足。
- **2、选 A3**：聚焦于通用大模型、前端和 Web 开发，A3 平台限制少，创新表达空间大，但需要认真准备知识库和演示数据。
- **3、选 A9**：适合物联网或移动端基础较强、希望控制实现风险的团队；但需要通过 OpenHarmony 适配体现特色。
- **4、谨慎选择 A4、A7、A8**：这些题目分别受调度算法、专用硬件或控制理论影响，专业门槛和准备成本更高。

我个人更倾向于 A3，之前做过类似的数据库项目。
