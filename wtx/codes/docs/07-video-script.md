## 镜头 5：照明中心（2:30–3:10）

## 镜头 6：三品牌空调（3:10–4:00）★重点

| 项 | 内容 |
|---|---|
| 操作 | 依次对格力/美的/海尔下发同一组指令 |
| 画面 | 终端打印：`GREE:MODE:0x01` / `MIDEA:MODE:0x02` / `HAIER:MODE:0x12` |
| 画面 | 再试点"海尔 + 除湿" → 提示"不支持"，模式按钮呈灰色 |
| 旁白 | "三个品牌的协议完全不同，但上层只有四个统一能力。品牌不支持的模式在界面直接置灰——新增品牌只加一个适配器，界面和场景规则一行都不用改。" |
| 对应需求 | FR-3.2–3.5 |
