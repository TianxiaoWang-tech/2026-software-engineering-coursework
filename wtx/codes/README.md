# 基于 OpenHarmony 操作系统的家居设备控制系统

第十五届中国软件杯大赛 A 组赛题 A9（出题企业：苏州未来网络研究院有限公司）

本地优先 · 三层加密 · 跨品牌空调兼容 · 无硬件可演示

---

## 快速开始

```bash
# 1. 一键演示（零依赖，Node ≥ 20）
node scripts/demo.mjs

# 2. 启动网关（含内置 MQTT Broker 与仿真家庭）
node gateway/main.mjs --broker --mqtt

# 3. 跑全部测试（46 项）
node scripts/test-all.mjs
```

启动后默认监听 `ws://127.0.0.1:8765`，账户：

| 账户 | 口令 | 权限 |
|---|---|---|
| admin | admin12345 | 全部 |
| member | member12345 | 控制 / 场景 |
| guest | guest12345 | 只读 |

## 目录结构

```
.
├── contracts/                     # 四份接口契约（冻结 v1.0，全员只读）
│   ├── model.d.ts                 #   实体/设备/区域/能力/场景/自动化
│   ├── driver.d.ts                #   驱动 SPI
│   ├── ac-adapter.d.ts            #   品牌空调适配器 SPI
│   └── gateway-api.d.ts           #   双端协议（含加密信封）
│
├── gateway/                       # 网关端（参考实现，ESM + 零依赖）
│   ├── core/                      #   事件总线、状态机、能力目录、日志、错误
│   ├── drivers/mqtt/              #   自研 MQTT 3.1.1（packet/client/broker/driver）
│   ├── drivers/sim/               #   仿真驱动（与真机同 SPI）
│   ├── adapters/ac-{gree,midea,haier}/   # 三品牌适配器
│   ├── services/                  #   统一控制、设备生命周期、API、WS 服务与客户端
│   ├── security/                  #   AEAD、KEK/DEK 密钥库、X25519、账户、会话
│   ├── domains/{lighting,climate,access,rules}/  # 四大中心业务
│   ├── app.mjs                    #   组合根
│   └── main.mjs                   #   进程入口
│
├── mobile/                        # HarmonyOS App（ArkTS，已编译签名并在模拟器验证）
│   └── entry/src/main/ets/        #   6 页面 + 加密客户端
│
├── simulators/                    # 设备仿真器（MQTT 灯/温湿度/空调）
├── scripts/                       # test-all.mjs、demo.mjs
├── tests/                         # 46 项自动化用例
├── docs/                          # 设计/手册/测试报告/PPT 大纲/视频脚本
├── prompts/                       # AI 提示词记录（A/B/C/D 各自独占）
├── 01~04 *.md                     # 需求与协作文档
└── _backup-团队版-20261101/        # 团队 V1.3/V2.1 文档留档
```

## 能力一览

| 中心 | 已实现 | 验证方式 |
|---|---|---|
| 照明 | 开关/调光/色温、人体感应自动亮灯、无人自动关灯 | 自动化用例 + 演示 |
| 温湿度 | 采集展示、阈值联动除湿/制冷（防抖） | 自动化用例 |
| 空调 | 格力/美的/海尔统一控制、能力子集置灰 | 码值断言 |
| 门禁 | 二次确认、访客拦截、留痕、自动上锁、未关告警 | 自动化用例 |
| 安全 | X25519 协商 + AES-256-GCM 信封 + 防重放 + KEK/DEK 轮换 | 篡改/重放/落盘检查 |

**架构约束（三条"零改动"）：** 新增协议 → 只实现 Driver SPI；新增品牌 → 只加适配器；新增设备类型 → 只加能力描述。
