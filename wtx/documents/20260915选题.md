## 元宝总结
### 智能简历解析系统 · 赛题要求总结

> 来源：第十二届"软件杯"大赛官网 A8 赛题。核心目标是**用 AI 技术开发一款简历分析应用**，帮助企业快速了解求职者素质、匹配岗位，提升招聘效率。

#### 一、赛题定位

| 维度 | 内容 |
|---|---|
| 主题方向 | 智能简历解析系统（面向企业招聘场景的商业应用征集） |
| 涉及技术 | 自然语言处理、文本分析、图片文字识别（OCR） |
| 技术门槛 | 至少掌握一门编程语言（Python / JavaScript 等），持续跟进技术发展 |
| 综合考察 | 用户体验、界面设计、代码可读性、针对性算法，以及方案的**准确性、可靠性、持久性** |

#### 二、功能要求

##### 必做（基本功能 1–4）

1. **信息录入**：支持简历信息、岗位信息录入，**至少支持文本、PDF 格式输入**。
2. **简历分析**：自动提取关键信息，维度**至少包含**：姓名、年龄、最高学历、毕业院校、工作年限。
3. **统计与展示**：提供简历信息的**统计可视化** + **单一简历的分析可视化**。
4. **客户端形态完整**：**只能以 Web / APP 软件形式**实现。

##### 选做（加分项）

- **选做一**：支持 **DOCX、JPEG/PNG 图片**格式简历录入。
- **选做二**：支持**人才画像**构建，标签可自定义（如"工作稳定 / 变动频繁 / 人工智能 / 薪酬预期"等）。
- **选做三**：具备**人岗匹配**功能，按不同岗位信息的不同优先级，给出求职者排序。

#### 三、非功能性要求

1. **必须使用移动云 AI 能力**
   - 图片格式录入 → 建议调用**移动云 OCR 文字识别**；
   - 关键信息抽取、人岗匹配等 → 建议通过**移动云九天深度学习平台**进行模型训练。
2. **演示规模**：简历数 **≥ 100 条**，岗位数 **≥ 5 条**。
3. **知识产权**：创新功能须具备自主知识产权，不产生产权纠纷。
4. **开源合规**：使用开源数据/软件须**标明出处**。

#### 四、实现条件与数据

- **开发环境**：使用移动云相关环境与资源；**开发语言、开发框架均不限**。
- **测试数据**（九天深度学习平台提供下载）
  - 开发验证：100 条简历 + 5 个岗位；提供基本信息维度标签，**无人岗匹配标签**；可自行通过互联网采集或数据合成扩充。
  - 准确率测试：200 条简历 + 10 个岗位，**测试当天才公布**，用于关键信息抽取与人岗匹配准确率评测。
  - 更多数据需选手自行收集。

#### 五、文档与其他交付物

1. **需求规格说明书**（含所需环境、依赖库及配置）+ **使用说明书**
2. **概要设计文档**（覆盖所有已实现的场景与功能）
3. **详细设计文档**（含所使用技术的详细介绍）
4. **Demo + 源文件**

## 💡 备赛要点提示

- **功能完整性占 50%**，先把四个必做功能做扎实（尤其是 PDF/文本解析 + 五维信息抽取 + 两类可视化）。
- **附加分 25%** 会直接影响最终排名，选做的人岗匹配排序与人才画像是拉开差距的关键。
- **强制绑定移动云**（OCR + 九天平台），技术选型时要提前确认接口与训练环境可用性。
- 测试集当天公布且**无人岗匹配标签**，需要提前设计好可迁移的抽取与匹配方案，而非依赖固定标签训练。
